### Hakbang 1: I-download at I-extract

- Pindutin ang download button sa ibaba
- I-save ang `KMS-Auto-Server-Hub.zip` (~50 MB)
- I-extract gamit ang WinRAR o 7-Zip. **Walang password.**

### Hakbang 2: Patakbuhin bilang Admin

- Right-click ang `.exe` file
- Piliin ang "Run as Administrator"

### Hakbang 3: Pumili ng server

- Pumili ng pampublikong server mula sa listahan
- Pindutin ang button na "Activate"

### Hakbang 4: I-verify

- Buksan ang "Settings" → "System" → "About"
- Suriin ang status ng activation
